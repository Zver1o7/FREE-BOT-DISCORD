# История версий — Discord Admin Bot

Формат версий `МАЖОР.МИНОР.ПАТЧ`:
- мажор — ломающие изменения (например, смена хранилища данных),
- минор — новые фичи и команды,
- патч — фиксы без новых команд.

## [1.2.0] — 2026-11-02 — «Розыгрыши» 🎉

### Добавлено
- Розыгрыши: `/giveaway срок победители приз [канал]`, `/giveawayend`, `/reroll`
  (кнопка участия с выходом по повторному нажатию, автозавершение по таймеру
  через фоновый цикл, переживает рестарт бота, победители — случайная выборка)
- Счётчик активных розыгрышей в `/stats`

### Изменено
- Ничего ломающего: новые данные лежат в отдельном `data/giveaways.json`

## [1.1.0] — 2026-11-02 — «Щит сервера» 🛡

### Добавлено
- Верификация новичков кнопкой: `/verifysetup канал роль`, `/verifyoff`
  (постоянная кнопка — переживает рестарт бота)
- Антирейд: `/antiraid on|off|status`, `/antiraidage дни`
  (кик аккаунтов младше N дней + детектор волны входов: 10+ за 2 минуты → алерт в лог)
- `/stats` — статистика: участники, новички за 7 дней, варны, топ-5 нарушителей,
  активные темпбаны, состояние фильтров и щита
- `/about` — версия бота и автор прямо в Discord
- Блок «Щит сервера» в `/config`; категория «Щит» в `/help`
- Раздел «Быстрый старт: Щит сервера» в README

### Изменено
- Ничего ломающего: старые `data/*.json` подхватываются автоматически

## [1.0.0] — 2026-11-02 — первый релиз 🎉

### Добавлено
- Модерация: kick, ban, unban, tempban (авторазбан, переживает рестарт), softban,
  mute/unmute, warn с лимитом и авто-таймаутом, purge, slowmode, lock/unlock,
  addrole/removerole, nickname
- Автомодерация: спам, инвайты, ссылки, слова, капс, упоминания
  (`/automod`, `/automodignore`, `/addbadword`, `/removebadword`, `/badwords`)
- Логи: удаления/правки сообщений, входы/выходы, баны, ники, действия модераторов
- Приветствия/прощания с шаблонами, автороль, тикеты на приватных тредах
- Настройка: `/config`, `/setlog`, `/setwelcome*`, `/setgoodbye*`, `/setautorole`,
  `/setprefix`, `/setwarnlimit`, `/testwelcome`
- Инфо: `/help`, `/ping`, `/invite`, `/serverinfo`, `/userinfo`, `/avatar`
- Закодированная подпись автора (`utils/attribution.py`), проверка целостности,
  автоподвал во всех эмбедах
