Полноценный **бот-администратор для Discord-серверов** на `discord.py 2.x`:
модерация, авто-модерация, логи, приветствия, тикеты и настройка через слэш-команды.
Весь интерфейс и сообщения — на русском. Все команды работают **и как слэш (`/команда`), и через префикс**.

---

## ✨ Возможности

| Блок | Что умеет |
| --- | --- |
| 🛡 **Модерация** | kick, ban (с чисткой сообщений 0–7 дней), unban по ID, временный бан (авторазбан через N времени, переживает перезапуск), softban, мут (таймаут) по длительности `30m` / `1h 30m` / `2d`, варны с сохранением и авто-таймаутом по лимиту, очистка чата, медленный режим, лок/разлок чата, выдача/снятие ролей, смена ников |
| 🤖 **Авто-модерация** | анти-спам ( окно N сообщений за K секунд), фильтр дискорд-инвайтов и любых ссылок, список запрещённых слов, фильтр чрезмерного капса, защита от спама упоминаниями; нарушения = авто-варн, 3 нарушения за 5 минут или превышение лимита варнов = авто-таймаут; модераторы и указанные каналы исключаются |
| 📜 **Логи** | в отдельный канал: удалённые и изменённые сообщения, вход/выход участников, бан/разбан (с кем и за что — из аудита), смена ников, все действия модератора и автомодерации |
| 👋 **Приветствия** | приветствие и прощание с шаблонами `{user}`, `{name}`, `{username}`, `{server}`, `{count}`, автороль для новичков |
| 🎫 **Тикеты** | приватный тред на запрос пользователя (`/ticket`), закрытие (`/ticketclose`) создателем или модератором |
| ⚙️ **Настройка** | префикс, лимит варнов, лог-канал, каналы приветствия/прощания и их тексты, автороль, тумблеры автомодерации, список слов — всё через команды |

**Защитные проверки:** нельзя наказать себя, бота и владельца сервера; нельзя действовать против участников с ролью выше/равной твоей или бота; перед каждой санкцией бот проверяет свои права и пишет понятную ошибку вместо падения.

## 📦 Установка

Нужен **Python 3.10+** (на Windows — галочка *Add python.exe to PATH* при установке).

```bash
git clone https://github.com/Zver1o7/discord-admin-bot.git
cd discord-admin-bot
python -m pip install -r requirements.txt
```

> Вместо `python` в Windows можно использовать `py`.

## 🔌 Подключение к Discord

1. Открой [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопируй токен.
3. Там же, секция **Privileged Gateway Intents** — включи оба:
   - ✅ **SERVER MEMBERS INTENT** (приветствия, автороль, вход/выход)
   - ✅ **MESSAGE CONTENT INTENT** (префикс-команды, анти-спам/фильтры)
4. Вкладка **OAuth2 → URL Generator**: scopes — `bot` + `applications.commands`;
   в **Bot Permissions** отметь (или проще — `Administrator`):
   
   `View Channels, Send Messages, Embed Links, Read Message History, Kick Members, Ban Members, Moderate Members, Manage Messages, Manage Roles, Manage Channels, Manage Nicknames, Manage Threads`
5. Открой сгенерированную ссылку и добавь бота на сервер. **Роль бота должна быть выше ролей тех, кого он будет наказывать** (перетащи её выше в списке ролей сервера).

## ⚙️ Настройка токена

Два способа на выбор:

**Вариант 1 — файл (удобно для локального запуска):**
```bash
cp config.example.json config.json
```
и впиши токен в `config.json`:
```json
{
  "token": "ВАШ_ТОКЕН",
  "guild_id": null
}
```

**Вариант 2 — переменная окружения (удобно на VPS/CI):**
```bash
# PowerShell (Windows)
$env:DISCORD_TOKEN = "ВАШ_ТОКЕН"

# Linux / macOS
export DISCORD_TOKEN=ВАШ_ТОКЕН
```

> 💡 **Слэш-команды появляются глобально до часа.** Для мгновенного теста впиши ID своего сервера
> в `guild_id` (или переменную `GUILD_ID`): команды синкаются моментально на него.
> ID сервера: ПКМ по серверу → «Копировать ID» (нужно включить режим разработчика в настройках Discord).

> `config.json` и папка `data/` в `.gitignore` — токен и данные (варны, баны) не попадут в git.
> Используй `config.example.json` как шаблон.

## 🚀 Запуск

```bash
python bot.py
```
или на Windows — просто двойной клик по `start.bat`.

В консоли появится `Запущен как Бот#0000`. Пришедшие ошибки пишутся понятным языком:
если забыл токен, не включил интенты или токен неверный — бот сразу скажет, что исправить.

## 📚 Команды

### 🛡 Модерация
| Команда | Описание |
| --- | --- |
| `/kick участник [причина]` | кикнуть |
| `/ban участник [удалить_сообщений 0-7] [причина]` | забанить |
| `/unban ID [причина]` | разбанить по ID |
| `/tempban участник срок [причина]` | временный бан (пример: `2h`, `3d`) |
| `/softban участник [причина]` | бан + чистка сообщений + разбан |
| `/mute участник срок [причина]` | таймаут (пример: `30m`, `1h 30m`, `7d`) |
| `/unmute участник [причина]` | снять таймаут |
| `/warn участник [причина]` | предупреждение (лимит → авто-таймаут) |
| `/warnings [участник]` | список варнов |
| `/delwarn участник номер` / `/clearwarns участник` | снять один / все варны |
| `/purge количество [участник]` | удалить сообщения (до 100, не закреплённые) |
| `/slowmode секунды [канал]` | медленный режим (0 — выключить) |
| `/lock [канал] [причина]` / `/unlock [канал]` | заблокировать/разблокировать чат |
| `/addrole участник роль` / `/removerole участник роль` | выдать/снять роль |
| `/nickname участник [новый_ник]` | сменить/сбросить ник |

### 🤖 Авто-модерация
| Команда | Описание |
| --- | --- |
| `/automod фильтр on\|off` | вкл/выкл: `спам`, `инвайты`, `ссылки`, `слова`, `капс`, `упоминания` |
| `/automodignore канал` | исключить канал из автомодерации |
| `/addbadword слово` / `/removebadword слово` / `/badwords` | список запрещённых слов |

### ⚙️ Настройка
| Команда | Описание |
| --- | --- |
| `/config` | сводка всех настроек |
| `/setlog [канал]` | лог-канал (без аргумента — отключить) |
| `/setwelcomechannel [канал]` / `/setwelcomemessage текст` | приветствие |
| `/setgoodbyechannel [канал]` / `/setgoodbyemessage текст` | прощание |
| `/testwelcome` | пример приветствия прямо сейчас |
| `/setautorole [роль]` | автороль новичкам |
| `/setprefix новый_префикс` | префикс для `!команд` |
| `/setwarnlimit число` | сколько варнов до авто-таймаута |

### 📊 Сервер и 🎫 Тикеты
| Команда | Описание |
| --- | --- |
| `/help` | все команды с описаниями |
| `/ping`, `/serverinfo`, `/userinfo [участник]`, `/avatar [участник]`, `/invite` | информация |
| `/ticket [причина]` | создать приватный тикет |
| `/ticketclose [причина]` | закрыть тикет (создатель или модератор) |

## 🧩 Структура проекта

```
discord-admin-bot/
├── bot.py               # точка входа: токен, интенты, слэш-синк, обработка ошибок
├── cogs/
│   ├── general.py       # help, ping, serverinfo, userinfo, avatar, invite
│   ├── moderation.py    # баны, муты, варны, purge, lock, роли, ник + фон авторазбана
│   ├── automod.py       # анти-спам, инвайты, слова, капс, упоминания + команды
│   ├── events.py        # логи: удаление/правки сообщений, join/leave, баны, ники
│   ├── welcome.py       # приветствия, прощания, автороль
│   ├── config.py        # настройка бота (/config, /setlog, /setwelcome*, ...)
│   └── tickets.py       # тикеты на приватных тредах
├── utils/
│   ├── settings.py      # JSON-хранилище: настройки, варны, временные баны
│   └── helpers.py       # парсинг времени, иерархия ролей, эмбеды, лог-хелпер
├── config.example.json  # шаблон config.json (токен + guild_id)
├── requirements.txt     # discord.py
├── start.bat            # запуск под Windows
└── data/                # создаётся автоматически: settings/warnings/tempbans.json
```

Данные хранятся в простых JSON-файлах (`data/`), настроек на каждый сервер — никаких БД
(для нагруженных серверов легко переделать на SQLite: всё обращение к данным изолировано в `utils/settings.py`).

## ❓ FAQ

**Слэш-команды не появились.** Глобальная синхронизация доходит до часа; для теста задай `guild_id` в `config.json` и перезапусти бота. Также обнови клиент: Ctrl+R.

**Бот не банит/не мутит участников.** Роль бота должна стоять **выше** ролей нарушителей, и у бота должны быть права (Kick/Ban/Moderate members и т.п.). Бот сам подскажет причину, если его прав не хватает.

**Бот пишет «отсутствуют привилегированные интенты».** Включи `SERVER MEMBERS INTENT` и `MESSAGE CONTENT INTENT` на странице бота в Developer Portal.

**Автомодерация не удаляет сообщения.** Она работает по `MESSAGE CONTENT INTENT`; также бот не фильтрует участников с правами модерации и каналы из `/automodignore`.

**Сломал/потерял данные.** Всё лежит в `data/*.json` — резервная копия это просто копия папки.
